# RETINA - Proactive Content Caching System

## 📌 Project Overview

RETINA (Realism-Oriented Intelligent Caching Framework) is a proactive content caching system designed for heterogeneous cellular networks (HetNets). The system improves cache hit ratio, reduces backhaul traffic, and minimizes latency by intelligently caching popular content at Small Base Stations (SBSs).

This project uses adaptive popularity prediction techniques to dynamically manage content caching in edge networks.

---

## 🚀 Features

* Intelligent content popularity prediction
* Proactive edge caching
* Dynamic cache replacement policy
* Reduced backhaul traffic
* Low latency content delivery
* SBS and Cloud coordination
* User preference-based caching
* Real-time cache management

## 🧩 Modules

### 1. Sender Module

Allows users to upload and distribute content into the system.

### 2. Receiver Module

Handles user requests and content retrieval.

### 3. SBS Module

Manages edge caching operations and cache replacement.

### 4. Cloud Module

Maintains centralized storage and synchronization with SBS nodes.
